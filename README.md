# زيتونة | Zaytouna Restaurant Website

موقع تجريبي تفاعلي لمطعم لبناني، مبني بـ HTML وCSS وJavaScript دون الحاجة إلى تثبيت أي مكتبات.

## تشغيل الموقع
1. فك ضغط ملف `zaytouna-restaurant.zip`.
2. افتح `index.html` بمتصفح حديث.
3. اتصال الإنترنت مطلوب لخط Google Fonts وصور الطعام الخارجية.

## الوظائف الموجودة
- تصميم متجاوب للموبايل والكمبيوتر.
- أقسام عروض وقائمة طعام.
- فلترة حسب التصنيف والبحث عن الوجبات.
- سلة مشتريات مع زيادة/تقليل الكميات وحساب المجموع.
- حفظ السلة والمفضلة باستخدام localStorage.
- نموذج طلب ينشئ رسالة واتساب تحتوي على الوجبات والمجموع وبيانات الزبون.
- قائمة تنقّل مناسبة للموبايل.

## مهم قبل النشر
- افتح `script.js` وعدّل `WHATSAPP_NUMBER` إلى رقم المطعم الحقيقي مع رمز الدولة، أرقام فقط. رقم واتساب التجريبي متروك كحماية حتى لا تذهب الطلبات إلى رقم غير صحيح.
- عدّل الأسعار والوصف والصور من مصفوفة `dishes` في `script.js`.
- عدّل رقم الهاتف وساعات العمل في `index.html`.
- الأسعار، العروض، رقم الهاتف، وساعات العمل الحالية أمثلة تجريبية وليست بيانات مطعم مؤكدة.
- الطلب يُرسل عبر WhatsApp بعد فتحه من جهاز المستخدم؛ لا توجد قاعدة بيانات أو لوحة إدارة أو نظام دفع إلكتروني في هذه النسخة.
- صور الطعام مستضافة خارجياً؛ استبدلها بصور مرخّصة أو صور المطعم قبل الاستخدام التجاري.

## الملفات
- `index.html` — بنية الموقع.
- `style.css` — التصميم والألوان والاستجابة للشاشات.
- `script.js` — القائمة، البحث، الفلاتر، المفضلة، السلة، وتجهيز طلب واتساب.
